# harness.tool.v1

Канон контракта вызова инструмента. Хаб этот каталог по сети не скачивает и JSON Schema не компилирует: вход и выход проверяет ручной строгий zod. Отдельного репозитория контракта нет. Ajv не используется.

Версия записана в `VERSION`.

## Состав

- `harness.tool.v1.request.schema.json`, `harness.tool.v1.response.schema.json`, `harness.tool.v1.http-error.schema.json` — конверт.
- `harness.services.v1.schema.json` — локальный манифест, который кладёт оператор. Обнаружения инструментов по сети нет.
- `tools/` — `read_file`, `list_dir`, `record_note`: имя, текст для модели, схема аргументов, `effect`, вызов `POST /v1/tools/{name}`.
- `examples/` — фиктивные uuid. Значений Authorization нет.
- Код рядом — ручная копия конверта и чистая сверка идемпотентности. Таблицы сервиса здесь нет.

Воркер и раннер этот каталог не импортируют. HTTP файлового сервиса отсюда не уходит.

Неизвестное поле конверта не отбрасывается. Чужое значение `contract` — `unsupported_version`. Лишнее поле при верной версии — `unknown_field`.

## Идемпотентность

Ключ записи — `<run_id>:<tool_call_id>` внутри кавычек заголовка `Idempotency-Key`. Тот же ключ и то же каноническое тело дают тот же ответ. Тот же ключ и другое тело — 409 `idempotency_conflict`. Чтение побочного эффекта не имеет: для `effect: read` сверка хранилище не читает.

Идентификаторы в конверте — строки. `chat_id` в теле нет.

## Расхождение с процессом

Имена `path` и `text` совпадают с `src/tools`. У `list_dir` поле `path` необязательное, как в коде.

В `src/tools/record-note.ts` аргумент `idempotency_key` обязателен (1..256). Повтор этого ключа не сравнивает тело и возвращает первый текст. Контракт следует спецификации: у сервиса в аргументах только `path` и `text`. Оставшийся `idempotency_key` — `unknown_field`. Хаб может снять поле с копии до отправки (`omitIdempotencyArgument`).

Потолок `text` в процессе — 65536 символов и 64 КиБ UTF-8. Здесь `maxLength` 32768, а тело вызова не больше 32 КиБ. Это жёстче, и разбор аргументов в раннере уже обрывается на 32 КиБ.

## Не инструменты хаба

Jira и длинный текст в `examples/not-hub-tools.md` — примеры того же конверта, не имена из `tools/`.
