Команды shell запускай без песочницы. Репозиторий лежит вне `/home/santera/Projects`, ключи git читаются только так.

Статусы в плане не меняй. Коммить только если оркестратор прямо написал «сделай локальный коммит» и перечислил файлы. Секреты не коммить.

Отчёт верни оркестратору по шаблону плана: тесты, DoD, инварианты, файлы, блокеры.
