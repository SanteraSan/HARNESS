# M3-P7. Внешний чат без инструментов и с минимальным размышлением

## Что сделано

Шов M3-P6 оставлен: ход `coder-cloud` и `provider = external` по-прежнему уходит без списка инструментов, без ключа `tools` и без результатов локальных инструментов. `tool_calls` в таком ответе завершают запуск `failed`, второго вызова и `execute` нет. Захват остаётся на OpenAI-совместимом раннере.

К копии системного промпта хода `coder-cloud` добавлена одна фраза: «В этом ходе инструментов нет. Ответь на вопрос сразу, не открывая файлы.» Строка агента и промпт локального хода не менялись. В тот же запрос пишется `reasoning_effort` со значением `none`. Алиас `agent`, запуск без выбора, API, cron и delegation это поле не получают и список `read_file` / `list_dir` не теряют.

В `ModelInput` добавлено только необязательное поле `reasoningEffort`. Других полей и миграций нет. Клиент пишет ключ, только если ход задал `none`, и не выбрасывает его при отказе шлюза: повторного вызова без поля нет.

## Ошибки и баги

Живой шлюз не вызывался, отказа на `reasoning_effort` в этом пакете не было. Обходной флаг не добавлялся. Первый прогон тестов на фейковом клиенте зелёный, ослаблять ожидания не пришлось. Сид локального allowlist не менялся.

## Вывод

Внешний чат после `/cloud` получает один вызов: без ключа `tools`, с `reasoning_effort: none` и с добавленной фразой. `tool_calls` в этом ответе дают `failed` без второго вызова. После `/local` уходят `read_file` и `list_dir`, ключа `reasoning_effort` нет. API-запуск ведёт себя как раньше.

Проверено: `node --env-file` на локальной тестовой базе, `vitest run test/runner test/model` — 9 файлов, 84 теста, все зелёные. Полный `vitest run` — 43 файла, 369 зелёных, 1 пропуск. Живого запроса к Gemini, OpenRouter и Ollama нет.
