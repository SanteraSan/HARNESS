# M3-P4. Админка

## Что сделано

Одна страница `web/index.html`: поле токена и четыре списка — запуски, шаги, агенты, кроны. Токен в файл страницы не записан, кнопки ввода только читают JSON. `GET /admin` отдаёт этот файл без bearer.

JSON: `GET /v1/admin/runs`, `GET /v1/admin/runs/:id/steps`, `GET /v1/admin/agents`, `GET /v1/admin/crons`. В SQL арендатор — литерал `local`, не параметр клиента. Не больше 100 строк. Чужой запуск на шагах — 404. Сравнение bearer — уже существующий `bearerMatches`. Пустой `HARNESS_ADMIN_TOKEN` и токен API эти маршруты не открывают. `POST /v1/runs` и `GET /v1/runs/:id` по-прежнему на `HARNESS_API_TOKEN`. Слушатель не менялся: `127.0.0.1`.

Секрет коннектора в ответе агента — имя и `secret: "••••"`. Шифртекст, nonce и salt не выбираются и не расшифровываются.

Каталог `web/` — тюрьма: `realpath`, отказ на `..` и на симлинк наружу, префикс только с разделителем. `eslint-disable` на `detect-non-literal-fs-filename` стоит потому, что путь файла приходит из URL и литералом быть не может: иначе `realpath` и ограниченное чтение не выразить. То же ограничение, что у проверки пути I19.

## Ошибки и баги

Первый прогон `test/api/admin.test.ts` зелёный: 10 тестов. Ожидания не ослаблялись.

После прогона ESLint показал три предупреждения. Два — `writeFile` и `symlink` в тесте: маркер HTML лежит во временном каталоге вне `web`, путь собирается в тесте. Закрыто точечным `eslint-disable-next-line` с этой причиной. Третье — обход ключей JSON через `value[key]`. Проверку ключей `ciphertext`, `nonce` и `salt` перенёс в текст ответа, динамического доступа не осталось.

Повторный прогон админки и `test/api/http.test.ts` зелёный: 2 файла, 26 тестов. Постановка запуска старым токеном API не сломалась.

## Вывод

Админка читает запуски, шаги, агентов и кроны только арендатора `local`, не больше 100 строк, без маршрутов записи. Секрет коннектора в JSON — маска, шифртекста нет. Страница открывается без bearer, токен в неё не записан. Путь `../` и симлинк наружу из `web/` не читаются.

## Замечания ревью

Лимит 100 на все связи сразу прятал секрет агента, если чужие имена шли раньше. Связи теперь читаются только для уже выбранных агентов, без второго лимита.

Пустые `final_text` и `response_excerpt` роняли весь список: разбор отвергал `''`. Пустая строка остаётся пустой строкой, `null` по-прежнему отсутствие.

Поздний ответ шагов затирал более новый выбор запуска. Страница рисует шаги только если номер выбора ещё текущий. Выбор запуска и обновление списков — разные счётчики: клик по старому запуску во время «Показать» не отменяет списки. Новый список сам отменяет ещё не пришедшие шаги.
